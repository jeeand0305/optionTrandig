==================================================
ПЛАН ПРОЕКТА: BOT RATIO SHORT SPREAD (CCXT / BYBIT)
==================================================

ЭТАП 1: ПОДГОТОВКА СРЕДЫ И БЕЗОПАСНОСТЬ
- Создание файла `.env` для API ключей.
- Настройка логирования всех действий в `bot.log`.
- Подключение Telegram-бота для алертов.

ЭТАП 2: ИНИЦИАЛИЗАЦИЯ БИРЖИ (CCXT)
- Создание класса `BybitOptionBot`.
- Настройка подключения к Единому аккаунту (UTA).
- Проверка доступного баланса маржи перед сделками.

ЭТАП 3: МОДУЛЬ СОЗДАНИЯ СПРЕДА (ВХОД)
- Функция сборки тикеров (DATE-STRIKE-TYPE).
    а. парсинг данних опционов и отбор интструментов 
        а.1 предложение инструмента для опционов
    б. парсинг данных дат опционов 
        б.1 предложение даты экспирации
    в. парсинг ближайше stryke 3 Put or 3 Call
        в.1 стоимость покупки и премия продажи
        в.2 выбор опционов покупок и продажи
        в.3 повторный показ выбранных опционов и повторое потверждение на покупку и продажу опциона

- Лимитный вход по Mid-price из стакана.
- Покупка x1 Call/Put + Продажа x2 дальних краев.

ЭТАП 4: СТЕЙТ-МАШИНА МОНИТОРИНГА
- Бесконечный цикл опроса цены базового актива.
- Расчет триггеров приближения к проданным страйкам.
- Внедрение буфера (гистерезиса) против рыночного шума.

ЭТАП 5: МОДУЛЬ ЗАЩИТЫ (ФЬЮЧЕРС)
- Расчет объема фьючерса для перекрытия x2 риска.
- Проверка маржи перед отправкой защитного ордера.
- Открытие фьючерса + выставление жесткого Стоп-Лосса.
- Обработка ошибок "Недостаточно маржи" с критическим оповещением.
