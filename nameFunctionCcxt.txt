Единый API ccxt представляет собой подмножество методов, 
общих для всех бирж. В настоящее время он содержит следующие 
методы:

fetchMarkets ()Функция получает список всех доступных рынков с биржи и возвращает массив объектов Market, определенных структурой Market (с такими свойствами, как symbol, base, quoteи т. д.). Некоторые биржи не имеют возможности получить список рынков через свой онлайн-API. В таких случаях список рынков жестко закодирован.
fetchCurrencies ()Функция получает все доступные валюты с биржи и возвращает ассоциативный словарь валют (объекты со свойствами, такими как code, name, и т. д.). Некоторые биржи не предоставляют возможности получения валют через свой онлайн-API. В таких случаях валюты извлекаются из рыночных пар или задаются жестко.
loadMarkets ([reload]): Возвращает список рынков в виде объекта, индексированного по символу, и кэширует его вместе с экземпляром биржи. Возвращает кэшированные рынки, если они уже загружены, если только флаг reload = trueне установлен принудительно.
fetchOrderBook (symbol, limit = undefined, params = {})Получение книги ордеров L2/L3 для конкретного торгового символа на рынке.
fetchStatus (params = {}): Возвращает информацию о статусе обмена либо из данных, жестко закодированных в экземпляре обмена, либо из API, если таковой имеется.
fetchL2OrderBook (symbol, limit = undefined, params): Книга ордеров второго уровня (агрегированная по цене) для конкретного символа.
fetchTrades (symbol, since, limit, params): Получение информации о последних сделках по конкретному торговому символу.
fetchTicker (symbol)Получите последние данные по тикеру по торговому символу.
fetchBalance (): Получение баланса.
